ลงทะเบียน Master Sample / Dummy Test ใหม่

สถานะควบคุม (Control Status):
รหัส Dummy (ID) ชิ้นงาน / รุ่น (Part / Model) ข้อบกพร่องจำลอง (Defect Type) จุดติดตั้ง (Station) วันที่ลงทะเบียน วันหมดอายุ สถานะ จัดการ / พิมพ์ Tag

บันทึกผลการตรวจสอบ Dummy Test ก่อนเริ่มงาน (Daily Verification)

ตามข้อกำหนด IATF 16949 ข้อ 10.2.4: ต้องทวนสอบอุปกรณ์ป้องกันความผิดพลาด (Error-Proofing) ด้วยชิ้นงาน Dummy ก่อนเริ่มกะผลิต

รายการ Dummy ที่ต้องทวนสอบประจำกะ (Active Dummies)

* ระบบล็อกอัตโนมัติไม่อนุญาตให้ใช้งาน Dummy ที่หมดอายุแล้ว

ประวัติการบันทึกผลตรวจสอบย้อนหลัง (Verification History Log)

วันที่ / เวลา กะ (Shift) รหัส Dummy จุดติดตั้ง / ชิ้นงาน ผลการ Test ผู้ทำการ Test หมายเหตุ / Containment Action ลบ

ตรวจสอบเครื่อง Packing ก่อนใช้งานประจำวัน (Pre-Use Weighing Verification)

หัวข้อการ Test: จำนวนถูกต้อง (ทำการทวนสอบด้วยการชั่งน้ำหนัก) • ครอบคลุมเครื่อง M/C : C2, E3, G4, H5, I6, J7

รายการเครื่อง Packing ที่ต้องทวนสอบก่อนเริ่มงาน (6 เครื่อง: C2, E3, G4, H5, I6, J7)

เกณฑ์ความคลาดเคลื่อนน้ำหนักมาตรฐานเริ่มต้น: ±1.0% (ปรับค่า Tolerance % รายเครื่องได้)
